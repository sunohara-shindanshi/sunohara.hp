# 「当社の特徴」のイラスト画像

このフォルダにイラスト画像を置くと、トップページの「当社の特徴」に自動的に反映されます（コードの変更は不要です）。

## 置き方

ファイル名を **特徴のID + 拡張子** にして、このフォルダに置いてください。

| ID           | 特徴                                         | 置くファイル名の例                  |
| ------------ | -------------------------------------------- | ----------------------------------- |
| `strength-1` | お金・人・売上・仕組みを、まとめて相談できる | `strength-1.png` / `strength-1.webp` |
| `strength-2` | 提案書を渡して終わりにしない                 | `strength-2.png` / `strength-2.webp` |
| `strength-3` | 最後は社内だけで回せるように                 | `strength-3.png` / `strength-3.webp` |

- 対応拡張子は `webp` / `png` / `jpg` / `jpeg` です。どれか1つを置けば反映されます。
- ファイルを置いていない特徴は、文字だけで表示されます（エラーにはなりません）。
- 画像は自動でWebP配信・最適化されます（`next/image` 経由のため）。
- 開発サーバー（`npm run dev`）を起動したままファイルを置いても、ページを再読み込みすれば反映されます。本番環境は再デプロイ時に反映されます。
- 特徴の文章・並び順は `lib/strengths.ts` で変更します。並べ替えても ID は変わらないので、画像がずれることはありません。

## 画像の目安

- 正方形に近い比率のイラスト（背景透過のPNGが特に綺麗に収まります）
- 表示サイズは 96px 四方です。1辺 400px 前後で十分です（大きすぎるファイルは表示速度に影響します）
