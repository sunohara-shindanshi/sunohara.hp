# 事業内容のイラスト画像

このフォルダに、各事業内容のイラスト画像を置くと自動的に反映されます（コードの変更は不要です）。

## 置き方

ファイル名を **事業内容のID + 拡張子** にして、このフォルダに置いてください。

| ID       | 事業内容   | 置くファイル名の例                          |
| -------- | ---------- | -------------------------------------------- |
| `finance`| 財務・資金 | `finance.png` / `finance.jpg` / `finance.webp` |
| `hr`     | 組織・人事 | `hr.png` / `hr.jpg` / `hr.webp`                |
| `sales`  | 営業・売上 | `sales.png` / `sales.jpg` / `sales.webp`       |
| `it`     | IT・システム | `it.png` / `it.jpg` / `it.webp`              |

- 対応拡張子は `webp` / `png` / `jpg` / `jpeg` です。どれか1つを置けば反映されます。
- ファイルを置いていない事業内容は、これまで通りの簡易アイコン表示のままになります（エラーにはなりません）。
- 画像は自動でWebP配信・最適化されます（`next/image` 経由のため）。
- 開発サーバー（`npm run dev`）を起動したままファイルを置いても、ページを再読み込みすれば反映されます（再起動は不要）。本番環境は再デプロイ時に反映されます。

## 画像の目安

- 正方形に近い比率のイラスト（背景透過のPNGが特に綺麗に収まります）
- 1辺 400px 前後で十分です（大きすぎるファイルは表示速度に影響します）
